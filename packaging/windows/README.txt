ChatGPT Model Switcher — Windows x64 portable

Extract the whole ZIP to a permanent folder, then double-click Start.cmd.
Python is included. Microsoft Edge WebView2 Runtime is required:
https://developer.microsoft.com/microsoft-edge/webview2/
Do not move/delete the folder while it is configured as a credential helper.
Use codex-switcher.cmd for CLI operations. Keys remain in the user's local
DPAPI-protected storage, not in this distribution.

完整解压到固定目录后，双击 Start.cmd 打开独立窗口。无需自行安装 Python。
如果没有 WebView2 Runtime，请从上述微软官方页面安装。
配置好后不要随意移动目录，凭据助手会引用此处的解释器。
Windows 尚不支持自动退出宿主并修复历史；请勿把 macOS 的重启功能视为 Windows 已验证能力。
